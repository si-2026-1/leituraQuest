# Requisitos Funcionais:

| Código | Descrição                                                     |
| ------ | ------------------------------------------------------------- |
| RF001  | Cadastro de alunos e professores.                             |
| RF002  | Autenticação por login e senha.                               |
| RF003  | Personalização do avatar do aluno.                            |
| RF004  | Biblioteca digital de livros e materiais didáticos.           |
| RF005  | Visualização de informações detalhadas dos livros.            |
| RF006  | Registro do progresso de leitura dos alunos.                  |
| RF007  | Sistema de pontuação e recompensas baseado em leitura.        |
| RF008  | Rankings individuais e coletivos dos alunos.                  |
| RF009  | Participação dos alunos em comunidades de leitura.            |
| RF010  | Criação de eventos e desafios de leitura por professores.     |
| RF011  | Distribuição de pontos e recompensas aos alunos por professores. |
| RF012  | Métricas e estatísticas de desempenho dos alunos.             |
| RF013  | Acompanhamento do desempenho individual e coletivo das turmas. |
| RF014  | Envio de avisos e comunicados para turmas.                    |
| RF015  | Histórico de leituras realizadas pelos alunos.                |
| RF016  | Busca de livros por título, gênero ou autor.                  |
| RF017  | Recomendação de livros com base nos interesses do usuário.    |
| RF018  | Visualização do perfil do aluno e de seu progresso.           |
