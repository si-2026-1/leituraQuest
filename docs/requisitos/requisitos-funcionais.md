# Requisitos Funcionais:

| Código | Descrição                                                                                |
| ------ | ---------------------------------------------------------------------------------------- |
| RF001  | O sistema deve permitir o cadastro de alunos e professores.                              |
| RF002  | O sistema deve permitir autenticação por login e senha.                                  |
| RF003  | O sistema deve permitir a personalização de avatar do aluno.                             |
| RF004  | O sistema deve disponibilizar uma biblioteca digital de livros e materiais didáticos.    |
| RF005  | O sistema deve permitir a visualização de informações detalhadas dos livros.             |
| RF006  | O sistema deve registrar o progresso de leitura dos alunos.                              |
| RF007  | O sistema deve possuir sistema de pontuação e recompensas baseado em leitura.            |
| RF008  | O sistema deve exibir rankings individuais e coletivos dos alunos.                       |
| RF009  | O sistema deve permitir a participação dos alunos em comunidades de leitura.             |
| RF010  | O sistema deve permitir que professores criem eventos e desafios de leitura.             |
| RF011  | O sistema deve permitir que professores distribuam pontos e recompensas aos alunos.      |
| RF012  | O sistema deve exibir métricas e estatísticas de desempenho dos alunos.                  |
| RF013  | O sistema deve permitir o acompanhamento do desempenho individual e coletivo das turmas. |
| RF014  | O sistema deve permitir o envio de avisos e comunicados para turmas.                     |
| RF015  | O sistema deve armazenar o histórico de leituras realizadas pelos alunos.                |
| RF016  | O sistema deve permitir a busca de livros por título, gênero ou autor.                   |
| RF017  | O sistema deve recomendar livros com base nos interesses do usuário.                     |
| RF018  | O sistema deve permitir a visualização do perfil do aluno e seu progresso.               |
