# Requisitos Não Funcionais

| Código | Tipo             | Descrição                                                                  |
| ------ | ---------------- | -------------------------------------------------------------------------- |
| RNF001 | Usabilidade      | Interface intuitiva e amigável para jovens estudantes.                     |
| RNF002 | Performance      | Tempo de resposta adequado nas operações principais.                       |
| RNF003 | Responsividade   | Funcionamento correto em dispositivos móveis.                              |
| RNF004 | Segurança        | Armazenamento seguro das senhas dos usuários.                              |
| RNF005 | Disponibilidade  | Disponibilidade de acesso durante o período escolar.                       |
| RNF006 | Escalabilidade   | Suporte a múltiplas turmas e usuários simultaneamente.                     |
| RNF007 | Acessibilidade   | Elementos visuais acessíveis e de fácil compreensão.                       |
| RNF008 | Manutenibilidade | Estrutura organizada para facilitar a manutenção futura.                   |
| RNF009 | Compatibilidade  | Compatibilidade com os principais navegadores e dispositivos móveis.       |
| RNF010 | Confiabilidade   | Integridade no armazenamento das informações dos usuários.                 |
