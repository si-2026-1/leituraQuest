# EP005 - Comunidades e Interação Social

Abrange funcionalidades relacionadas à interação entre alunos.

## HU11 - Participação em Comunidades

### Descrição

Como aluno, quero participar de comunidades de leitura para interagir com outros estudantes.

### Critérios de Aceitação

* O sistema deve permitir entrada em comunidades;
* O sistema deve exibir comunidades disponíveis;
* O sistema deve exibir participantes da comunidade;
* O sistema deve permitir saída da comunidade;
* O sistema deve registrar participação do aluno.

## HU12 - Interação em Comunidades

### Descrição

Como aluno, quero interagir em comunidades para compartilhar experiências de leitura.

### Critérios de Aceitação

* O sistema deve permitir publicação de mensagens;
* O sistema deve exibir interações dos participantes;
* O sistema deve permitir visualização de conteúdos compartilhados;
* O sistema deve organizar mensagens por comunidade;
* O sistema deve atualizar interações em tempo real.
