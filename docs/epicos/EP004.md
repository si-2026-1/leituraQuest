# EP004 - Gamificação e Rankings

Abrange funcionalidades relacionadas ao sistema de pontuação, níveis e recompensas.

## HU09 - Sistema de Pontuação

### Descrição

Como aluno, quero ganhar pontos ao realizar leituras para acompanhar minha evolução.

### Critérios de Aceitação

* O sistema deve atribuir pontos por leituras realizadas;
* O sistema deve atualizar a pontuação automaticamente;
* O sistema deve exibir a pontuação do aluno;
* O sistema deve registrar histórico de pontuação;
* O sistema deve permitir progressão de níveis.

## HU10 - Rankings

### Descrição

Como aluno, quero visualizar rankings para comparar meu desempenho com outros estudantes.

### Critérios de Aceitação

* O sistema deve exibir ranking de alunos;
* O sistema deve atualizar posições automaticamente;
* O sistema deve exibir pontuação dos participantes;
* O sistema deve permitir rankings individuais e coletivos;
* O sistema deve destacar a posição do aluno logado.
