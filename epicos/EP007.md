# EP007 - Eventos e Avisos

Abrange funcionalidades relacionadas à comunicação e desafios pedagógicos.

## HU15 - Criação de Eventos

### Descrição

Como professor, quero criar eventos e desafios para incentivar a participação dos alunos.

### Critérios de Aceitação

* O sistema deve permitir cadastro de eventos;
* O sistema deve permitir definir data e descrição;
* O sistema deve exibir eventos disponíveis;
* O sistema deve permitir associação de recompensas;
* O sistema deve notificar os alunos participantes.

## HU16 - Envio de Avisos

### Descrição

Como professor, quero enviar avisos para manter os alunos informados.

### Critérios de Aceitação

* O sistema deve permitir envio de avisos para turmas;
* O sistema deve exibir data da publicação;
* O sistema deve permitir visualização dos avisos pelos alunos;
* O sistema deve armazenar histórico de avisos;
* O sistema deve organizar avisos por turma.
