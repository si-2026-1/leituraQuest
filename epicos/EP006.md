# EP006 - Gestão Pedagógica

Abrange funcionalidades relacionadas ao acompanhamento realizado pelos professores.

## HU13 - Acompanhamento de Desempenho

### Descrição

Como professor, quero acompanhar o desempenho dos alunos para avaliar sua evolução.

### Critérios de Aceitação

* O sistema deve exibir métricas de desempenho;
* O sistema deve exibir progresso individual dos alunos;
* O sistema deve exibir estatísticas das turmas;
* O sistema deve atualizar os dados automaticamente;
* O sistema deve permitir visualização de rankings.

## HU14 - Gerenciamento de Recompensas

### Descrição

Como professor, quero distribuir recompensas para incentivar os alunos.

### Critérios de Aceitação

* O sistema deve permitir atribuir pontos aos alunos;
* O sistema deve registrar recompensas distribuídas;
* O sistema deve atualizar rankings automaticamente;
* O sistema deve exibir confirmação da distribuição;
* O sistema deve impedir pontuações inválidas.
