# EP001 - Autenticação e Acesso ao Sistema

Abrange funcionalidades relacionadas ao cadastro, login e recuperação de acesso dos usuários.

## HU01 - Cadastro de Usuário

### Descrição

Como usuário, quero realizar meu cadastro no sistema para acessar a plataforma.

### Critérios de Aceitação:

- O sistema deve permitir cadastro de alunos e professores;
- O sistema deve solicitar nome, e-mail, senha e informações escolares;
- O e-mail deve ser validado quanto ao formato;
- O sistema deve impedir cadastros duplicados;
- O sistema deve confirmar o cadastro com mensagem de sucesso.

## HU02 - Login no Sistema

### Descrição:

Como usuário, quero realizar login utilizando e-mail e senha para acessar minha conta.

### Critérios de Aceitação

- O sistema deve disponibilizar campos de login e senha;
- O sistema deve validar as credenciais informadas;
- O sistema deve exibir mensagem de erro em caso de dados inválidos;
- O sistema deve redirecionar o usuário para a página inicial após autenticação;
- O sistema deve manter a sessão do usuário ativa durante o uso.

## HU03 - Recuperação de Senha

### Descrição

Como usuário, quero recuperar minha senha para voltar a acessar minha conta em caso de esquecimento.

### Critérios de Aceitação

- O sistema deve possuir opção de recuperação de senha;
- O sistema deve solicitar o e-mail cadastrado;
- O sistema deve permitir redefinir a senha;
- O sistema deve confirmar a alteração da senha;
- O sistema deve impedir redefinições com senhas inválidas.
