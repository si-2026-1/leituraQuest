# EP002 - Perfil e Personalização do Usuário

Abrange funcionalidades relacionadas ao perfil do aluno e personalização visual.

## HU04 - Personalização de Avatar

### Descrição

Como aluno, quero personalizar meu avatar para representar minha identidade no sistema.

### Critérios de Aceitação

* O sistema deve permitir alterar avatar;
* O sistema deve disponibilizar opções visuais de customização;
* O avatar deve ser exibido no perfil do aluno;
* O sistema deve salvar as alterações realizadas;
* O avatar deve aparecer em rankings e comunidades.

## HU05 - Visualização de Perfil

### Descrição

Como aluno, quero visualizar meu perfil para acompanhar meu desempenho e progresso.

### Critérios de Aceitação

* O sistema deve exibir informações do aluno;
* O sistema deve exibir nível, pontuação e progresso;
* O sistema deve exibir histórico de leituras;
* O sistema deve exibir posição em rankings;
* O sistema deve atualizar os dados automaticamente.
